
# Vigil

**Interactive Cybersecurity Awareness and Learning Platform**

Vigil is a web-based cybersecurity awareness platform designed to help users understand, practise and improve their cybersecurity knowledge through guided learning, scenario-based assessments and interactive simulations.

## Technology Stack

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Backend
- Python
- Django
- Django REST Framework

### Database
- PostgreSQL
- Django ORM

### Development and Collaboration
- Git
- GitHub
- Postman
- Pytest

## Core Features

- Guided cybersecurity learning modules
- Initial scenario-based knowledge assessment
- Module-specific quizzes
- Interactive cybersecurity simulations
- Password strength checker
- Personal learning progress reports
- Administrative dashboard and content management
